## Overview

Unit 2 assignment for **Automation in Software Development** (V Semester,
Jain University). The brief required using an AI coding assistant *other
than GitHub Copilot* to build a small CLI/library from scratch, applying
three prompting techniques — zero-shot, few-shot, and chain-of-thought —
and documenting every prompt verbatim.

Tool used: an **agentic CLI coding assistant** (terminal-based, backed by a
frontier LLM) — explicitly permitted by the brief. Task chosen: **Option A**.

The result is an **expense splitter**: it splits shared expenses fairly among
a group and reports the minimal set of cash transfers needed to settle up.
7 public functions/classes, 14 passing unit tests, built over 9 documented
prompts (5 zero-shot, 2 few-shot, 2 chain-of-thought) and 11 incremental
commits in the original repository.

## Known limitations

- Because the tool is a terminal agent (no GUI), the "screenshots" are
  terminal-style renders of the real session exchanges, generated by
  `docs/make_screenshots.py` — noted transparently in the PDF as well.
- The debt simplifier uses a greedy two-pointer settlement: minimal in
  transfer count for the tested cases, but not proven globally optimal
  for arbitrary balance graphs.
